PDF 工具箱 v1.0.3 — 完全离线交付
日期：2026-11-02

一、三个版本

1. Windows 7：exe\Windows7\PDF工具箱-Win7.exe
   适用于 Windows 7 SP1 32/64 位。复制整个 Windows7 文件夹即可。
2. Windows 10：exe\Windows10\PDF工具箱-Win10.exe
   适用于 Windows 10 64 位。32 位 Windows 10 可使用 Windows7 兼容版。
   复制整个 Windows10 文件夹即可。
3. 信创 Linux（含欧拉适配目标）：exe\信创Linux\start.sh
   提供 x86_64、ARM64、LoongArch64 三种 CPU 程序，启动脚本自动选择。
   复制整个“信创Linux”文件夹，按其中“部署说明.txt”启动。

Windows 的 EXE 不能在 Linux 上运行，因此信创版是 Linux 可执行程序和启动脚本。
各版本均包含离线运行所需的 Word 引擎；部署时无需联网下载依赖。
Windows 版每份约 1.4 GB，信创包约 0.8 GB，首次运行解包还需要磁盘空间。

二、Windows 使用

双击相应 EXE，程序在默认浏览器里打开中文界面。
不需要安装 Python、Java、Go 或 Microsoft Office。
EXE 旁的 LibreOffice 文件夹必须完整保留，Word 转换需要用到它。
图片转换由主程序自身完成，不依赖办公软件。

Windows 7 要求 SP1。若系统提示缺少 api-ms-win-crt-*.dll，先离线安装
Windows7\运行库补丁 中与“操作系统位数”对应的 KB2999226 补丁，必要时重启。
系统已经安装该补丁时无需重复安装。VC++ 运行库 DLL 已随引擎放好。
浏览器需要支持 HTML5 文件接口；不支持 IE8/IE9。浏览器本身由电脑提供。

三、图片顺序与生成 PDF

1. 选择或拖入多张照片。
2. 用每张照片旁的“↑ / ↓”调整顺序，也可以单独移除。
3. 列表从上到下就是 PDF 第 1、2、3……页的顺序。
4. 选择 A4、Letter 或图片原尺寸，设置页面方向和页边距。
5. 点击“生成 PDF”，完成后点击“下载 PDF”。

支持 JPG/JPEG、PNG、BMP、GIF、TIF/TIFF。
每张图片一页；GIF/TIFF 仅取第一帧/第一页。
自动处理 JPEG/TIFF 的 EXIF 方向；透明背景转为白色；图片等比例居中。
原尺寸按 96 DPI 换算。输出采用高质量 JPEG 压缩，不含 OCR 文字识别。
单张不超过 50 MB、2000 万像素、单边 20000 像素。
每批最多 200 张，总计不超过 200 MB。

四、Word 转 PDF

支持真正的 .doc / .docx。选择一个文档下载 PDF；选择多个文档下载 ZIP，
每个 Word 对应一个 PDF，不会自动合并多个 Word。
单个最多 50 MB，每批最多 20 个、总计 200 MB。
保留文字、表格、图片和分页；复杂排版、特殊字体与 Word 可能有差异。
不支持密码保护文档。单文档最多等待 2 分钟，整批最多 5 分钟。
首次启动引擎可能较慢，界面会持续显示处理状态，可以取消。

五、离线与文件清理

程序界面和依赖都在本地，不使用 CDN、在线字体或在线转换服务。
Windows 默认只监听本机。信创版供内网浏览器访问，文件由你部署的服务器处理。
Word 引擎使用独立临时配置，关闭宏及自动更新检查/自动下载。
上传文件在转换完成后清理，结果保留 60 分钟，正常退出时一并清理。
关闭网页不会退出程序；Windows 点击右上角“退出程序”。
断电或强制终止可能遗留系统临时文件；原始照片和 Word 不会被修改。

六、验证范围

两个 Windows EXE 都在当前 Windows 10 x64 环境完成实际转换验证。
Win7 兼容编译使用 Go 1.20.14，尚未在 Windows 7 实机验收。
信创三个架构已编译，随包运行库经过 ELF 架构和动态依赖检查，含中文字体。
欧拉、麒麟、统信及各 CPU 的实机转换尚未验证，不把静态检查等同于认证。
LoongArch64 面向上游 ABI / Linux 5.19+，不适用于旧 MIPS 龙芯或旧 ABI。
信创离线启动需要管理员权限建立独立运行目录，服务随后以普通 UID 65534 运行。

源码及构建、测试脚本见“源码”。验证证据见 源码\测试证据。
完整部署边界和操作步骤见 exe\信创Linux\部署说明.txt。

新增 html/index.html：单文件网页，支持 ZIP 数字排序和多图手动排序。
