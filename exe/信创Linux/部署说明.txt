信创 Linux / 欧拉 离线部署

本目录自带三个架构的主程序、LibreOffice、所需运行库、Noto CJK 中文字体。
部署和运行不调用 apt、dnf、pip、curl、wget 或 Docker 拉取依赖。
运行环境来自官方 Debian 软件包，放在程序独立目录内，不向宿主系统安装 DEB/RPM，
不改变欧拉/麒麟/统信的包数据库。使用 chroot 让引擎使用随包库而非宿主库。

一、目标范围

x86_64：海光、兆芯及其他 x86_64 兼容服务器。
ARM64：鲲鹏、飞腾及其他 AArch64 服务器。
LoongArch64：上游 ABI、Linux 5.19 及以上；不适用旧 MIPS 或旧 ABI 龙芯。
欧拉（openEuler / EulerOS）、麒麟、统信是部署适配目标，尚无实机认证结果。
本包要求 Linux 内核允许 chroot、proc 挂载，具备常规系统命令 tar/gzip、
sha256sum、chroot、mount、umount、mknod、id、env、cp、chmod、chown。
这些是宿主系统的基础能力；若被精简或安全策略禁止，请由管理员先确认。
不是 Windows EXE，不要求服务器安装桌面或浏览器；在内网客户端浏览器操作。

二、离线启动

把“信创Linux”整个文件夹复制到服务器，例如 /opt/pdf-tool。
建议至少 2 GB 可用内存、4 GB 可用磁盘。首次解包对应架构可能需要几分钟。
进入目录后执行：
  sudo sh start.sh

脚本自动识别 CPU、校验运行环境 SHA-256、解包到 runtime-架构 目录。
管理员权限仅用于建立 chroot 运行环境、设备节点和 proc 挂载，应用以
UID/GID 65534 运行。不会注册系统服务、修改防火墙或替换系统库。
停止时按 Ctrl+C，脚本会停止程序并卸载此次 proc 挂载。

默认监听 0.0.0.0:8080。启动信息包含随机口令和完整地址。
将地址中的 127.0.0.1 换为服务器内网 IP，在内网浏览器打开完整地址。
访问口令不能省略。不同次启动的随机口令不同。

固定口令、指定端口的示例（在管理员 shell 中）：
  export PDF_TOOL_TOKEN='替换为至少16位的随机口令'
  sh start.sh --listen 0.0.0.0:8080

仅让服务器本机或已有反向代理访问：
  sudo sh start.sh --listen 127.0.0.1:8080

无需连接互联网。默认包中不含微软商业字体，若业务文档使用特定字体，
请把合法取得的字体离线复制到 runtime-架构/usr/local/share/fonts，重启服务。

三、三个架构的文件

pdf-tool-linux-amd64 / runtime-amd64.tar.gz：x86_64
pdf-tool-linux-arm64 / runtime-arm64.tar.gz：ARM64
pdf-tool-linux-loong64 / runtime-loong64.tar.gz：LoongArch64

运行环境压缩包、SHA-256、来源清单和静态验证结果在“离线运行环境”目录。
x86_64/ARM64 运行环境基于 Debian bookworm；LoongArch64 基于 Debian unstable
原生架构包。每份独立运行环境都包含相应的 libc 等依赖。
这只是应用私有运行目录，不会把服务器操作系统换成 Debian。

四、运维

同一目录只允许一个实例。异常强制终止可能留下 .running-架构 锁目录。
确认原进程已停止、runtime-架构/proc 已卸载后，才可删除该空锁目录重启。
不要在 proc 挂载仍存在时递归删除 runtime 目录。

正常 Ctrl+C 会清理转换任务临时文件，服务结果保留 60 分钟。
每个进程一次处理一个任务，其他请求会收到稍后重试提示。
源码/deploy/pdf-tool.service 提供 systemd 模板，须由管理员按路径调整并启用。
模板以 root 启动准备脚本，应用本身由脚本降权，不会以 root 执行文档转换。
该工具使用共享访问口令，不是多租户账号系统；按内网受控服务部署。
如接入现有反向代理，上传上限设为至少 210 MB，响应超时至少 6 分钟，保留 Host。

五、验收范围

当前完成三个 Linux ELF 主程序交叉编译、SHA-256 校验、每架构引擎及其
130 个 ELF 对象依赖闭包检查、中文字体检查、启动脚本语法检查。
尚未在欧拉/麒麟/统信或 ARM/龙芯实机执行，不承诺所有版本免验证通用。
首次部署请使用中文表格、图片、分页等真实业务文档核对转换结果。
