PDF 文件工坊 K8S 镜像 v1.2.1

新增 RAR（RAR4/RAR5）、7Z 图片导入；保留 ZIP、多图排序及 DOC/DOCX 转 PDF。
移除页面部署标签、英文标语、装饰编号和底部处理说明。
镜像内置网页、Go 程序、LibreOffice、中文字体、7-Zip 26.06 和运行库。
部署和运行时无需联网安装依赖，不需要宿主机 Nginx。

本批镜像时间：20261116220524（北京时间，14 位年月日时分秒）。
按实际运行 Pod 的服务器 CPU 选择，不按访问网页的电脑系统选择：

- aarch64 / 鲲鹏 / 飞腾：word-pdf-20261116220524-arm64.tar.gz
  docker load -i word-pdf-20261116220524-arm64.tar.gz
  预期输出：Loaded image: word-pdf-20261116220524-arm64:1.2.1
两份镜像功能相同，内部程序和解压引擎均匹配各自 CPU 架构。
本批不含龙芯容器镜像，不能把 amd64 或 arm64 镜像部署到 LoongArch 节点。
同名 .sha256 文件用于校验。

容器端口 8080，网页路径 /。启动命令已内置，无需覆盖 command / args。
镜像上传到所有候选节点可访问的内网镜像仓库，K8S 引用仓库地址。
仅在某台 ECS 上 docker load 不会自动分发到其他节点。
通过已有 Service / SLB 暴露后，访问 IP:端口即可。
混合 CPU 集群应按 kubernetes.io/arch 调度，或在内网仓库组合多架构清单。
Win7、Win10、信创电脑使用兼容的 Chrome、Edge 或 Firefox 访问相同网址。

多副本和文件处理
不配置任何外部 volumeMounts、hostPath、PVC、共享目录或会话粘滞。
运行依赖全部在镜像内，扩容 Pod 不需要往对应 ECS 目录上传文件。
/tmp 使用容器自身可写层，不启用 readOnlyRootFilesystem。
SLB/K8S 负责流量分发，程序不做轮询。
Word PDF 在同一次 POST 响应中直接返回浏览器，不产生后续 Pod 下载地址。
RAR/7Z 在单次请求内解压并返回图片，接下来在浏览器中排序和生成 PDF。
ZIP 和直接选择的图片继续在浏览器处理。
每个请求完成、失败或取消后清理临时文件；不保留上传文件、PDF、转换历史。
已返回浏览器的结果不依赖原 Pod；强制终止正在执行的请求时仍需重试。
每个 Pod 同时执行一个 Word/压缩包任务，繁忙时提示稍后重试。

文件限制
压缩包不超过 200 MB，解压后最多 200 张、总计 200 MB，单张不超过 50 MB。
支持单个未加密压缩包、子文件夹和自然数字排序（1、2、3、10）。
暂不支持密码保护和分卷压缩包，请先合并或移除密码。
Word 单个 DOC/DOCX 不超过 50 MB；复杂版式和缺失字体可能影响效果。

K8S 参数
livenessProbe: GET /healthz，端口 8080。
startupProbe / readinessProbe: GET /readyz，端口 8080。
启动先真实转换测试 Word；建议启动探针窗口 180 秒。
terminationGracePeriodSeconds 建议 400；代理/SLB 请求超时建议至少 360 秒。
SIGTERM 后停止就绪，留 5 秒传播窗口，最多等待在途请求 360 秒。
默认 UID/GID 65534，不需要 privileged、Docker socket 或附加 capability。
解压子进程设有时间、输出和内存上限；临时可写层需预留足够空间。
