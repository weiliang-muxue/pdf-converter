下一版本镜像命名要求
用户确认日期：2026-11-16（北京时间）

仅从下个版本开始生效。本次 v1.2.1 已交付镜像、文件名、Release 附件和标签全部保持不变，不因此重建或重发。

将版本号从 Docker 标签移入镜像仓库名，用连字符连接：
word-pdf-14位北京时间-架构标识-版本号
用户给出的格式示例：word-pdf-20261116220524-amd-1.2.1
下一版使用新的实际时间和版本号，不复用示例中的旧批次和版本号。

amd64/x86_64 平台按用户示例使用 amd 名称标识；镜像配置 architecture、内部 ELF 程序和实际平台仍必须是 amd64。
arm64 平台使用 arm64 标识，不能把所有架构都写成 arm64。
同批次各架构共用同一个 14 位北京时间，文件名、镜像名、校验文件、构建验证、工作流及交付说明同步对应。
归档文件名：word-pdf-14位北京时间-架构标识-版本号.tar.gz。

Docker 未指定标签时默认 latest。标准完整镜像引用应是：
word-pdf-14位北京时间-架构标识-版本号:latest
不要承诺 docker load 的完整输出完全没有冒号；版本号与架构之间改为连字符，默认标签按 Docker 规则处理。
官方格式说明：https://docs.docker.com/reference/cli/docker/image/tag/

本次只记录要求，不修改当前构建配置或运行代码。下次实际发行时再落实并验证 docker load 输出。
